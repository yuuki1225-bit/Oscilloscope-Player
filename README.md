# Oscilloscope Player

オシロスコープに動画を描画できるソフトウェアです。ESP32を使用して、動画データをアナログ信号として出力します。（たぶん）

## 用意するもの

### ハードウェア
- アナログオシロスコープ
- ESP32
- PC (Windows 10以上推奨)

### ソフトウェア
- Oscilloscope_Player.exe (同梱)
- Arduino IDE
- 映したい動画ファイル (mp4形式)

## 使い方

1. **Arduino IDE**でESP32に `oscilloscope_player.ino` を書き込んでください。
2. ESP32とオシロスコープをつなぎます。
   - **GPIO 26**: 縦軸 (Y軸)
   - **GPIO 25**: 横軸 (X軸)
3. `Oscilloscope_Player.exe` を起動します。
4. 映したい動画ファイルが入ったディレクトリを指定します。
5. シリアルポートを接続したESP32のものに設定してください。
6. 必要であればパラメーターを調整します。
7. **[連続再生開始]** ボタンを押してください。
8. 準備が始まるのでお待ちください（環境によって時間がかかる場合があります）。
9. 再生が始まります。
